# PDF Changer — 양면 스캔 PDF 페이지 재정렬

**책이나 문서를 앞면 묶음·뒷면 묶음으로 스캔했을 때, 페이지를 읽는 순서로 다시 배열하는 브라우저 도구**입니다. 파일을 업로드하고 재정렬한 PDF를 다운로드할 수 있습니다.

## 어떤 파일에 사용하나요?

한쪽 면을 순서대로 모두 스캔하고, 종이를 뒤집어 반대쪽 면을 **역순**으로 스캔한 PDF를 가정합니다. 예를 들어 원본 파일이 다음과 같을 때:

```text
원본 순서:   1, 3, 5, 6, 4, 2
재정렬 결과: 1, 2, 3, 4, 5, 6
```

코드에서는 앞쪽 절반을 정방향으로, 뒤쪽 절반을 역방향으로 번갈아 가져오는 인덱스 계산을 사용합니다.

## 사용 방법

1. `index.html`을 브라우저로 열거나 로컬 웹 서버를 실행합니다.
2. PDF를 선택하거나 드래그 앤 드롭합니다.
3. 재정렬을 실행합니다.
4. 생성된 PDF를 다운로드하고 실제 페이지 순서를 확인합니다.

```bash
git clone https://github.com/junhy1203/pdfchanger.git
cd pdfchanger
python -m http.server 8080
```

접속: `http://localhost:8080`

## 기술 스택

- **HTML / CSS / JavaScript:** 파일 선택, 진행 상태, 다운로드 UI
- **PDF-Lib:** 브라우저에서 PDF 문서를 열고 페이지를 복제·재조합
- `app.js`: 업로드 및 UI 로직
- `reorder.js`: 페이지 재배열 알고리즘

## 제한사항

이 도구는 **페이지 순서만 변경**합니다. PDF 내용 인식(OCR), 자동 양면 감지, 잘못 스캔된 페이지 복구는 수행하지 않습니다. 특정 스캔 순서를 전제로 하므로 일반 PDF나 다른 스캔 방식의 파일에는 적합하지 않을 수 있습니다. 출력물을 반드시 미리 확인하세요.
